# CourtVision

A lightweight, browser-based basketball play-practice prototype.

## Run locally
Open `index.html` in a modern web browser. No build step or package installation is required.

## Publishing
The GitHub Actions workflow at `.github/workflows/pages.yml` enables GitHub Pages for this repository and deploys the static site from the repository root. New pushes to `main` redeploy it automatically.

## Prototype notes
The prototype is an early visual MVP. It uses scripted player positions and simplified visuals; it is not a full physics-based 3D game and does not include accounts or cloud persistence.

## Source
`index.html` is the current page retrieved from the active CourtVision Vercel deployment on November 21, 2026.
